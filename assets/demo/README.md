This folder is where a bundled `sample_certificate.pdf` should be placed for
fully offline demo-mode certificate downloads.

It is not included in this build (binary assets aren't generated by the
assistant that built this codebase). To complete demo mode's certificate
download end-to-end:

1. Generate any sample PDF (e.g. export the `issue-certificates` Edge
   Function's `buildCertificatePdf()` output locally with a Deno script,
   or just drop in any placeholder PDF).
2. Save it as `assets/demo/sample_certificate.pdf`.
3. It's already declared under `flutter: assets:` in `pubspec.yaml`.

Until then, `MyCertificatesScreen` in demo mode will show a "downloaded"
confirmation snackbar without a real file (see the `demo://` URL branch in
`DemoCertificateRepository.signedDownloadUrl`), which is called out in
TASKS.md as a partial item.
